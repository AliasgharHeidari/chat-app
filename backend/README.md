# 💬 Chat App - Messaging Platform

A real-time private messaging application built with **Go Fiber**, **WebSocket**, **PostgreSQL**, and **GORM**. Features JWT authentication, private chats, message status tracking, typing indicators, and online status.

## ✨ Features

- 🔐 **JWT Authentication** - Secure login/register with JSON Web Tokens
- 💬 **Private Chats** - One-on-one real-time messaging
- ✅ **Message Status** - See when messages are sent, delivered, and read
- ✏️ **Edit/Delete Messages** - Edit or delete sent messages
- 🟢 **Online Status** - See when users are online
- ⌨️ **Typing Indicator** - Know when someone is typing
- 🔍 **User Search** - Find users by username, first name, or last name
- 👤 **Profile Management** - Update profile info and avatar
- 📱 **Responsive Design** - Works on desktop and mobile

## 🛠️ Tech Stack

### Backend
- **Go 1.21+** - Main programming language
- **Fiber** - Web framework
- **GORM** - ORM for database operations
- **PostgreSQL** - Primary database
- **WebSocket** - Real-time communication
- **JWT** - Authentication
- **Bcrypt** - Password hashing
